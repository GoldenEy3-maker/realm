# 01 — Vision

Статус: Draft v0.3 · Обновлено: 2026-08-04

## Продукт

**Realm** — платформа для управления бизнес-процессами команды. В одном workspace команда ведёт проекты, задачи, планирование, видит активность и общается в чате.

Рабочее название: Realm (может измениться).

## Проблема

Команды размазывают работу по нескольким инструментам (таск-трекер, календарь, чат, тайм-трекинг). Контекст теряется: статус задачи в одном месте, обсуждение в другом, план дня — в третьем. Realm собирает кор в одном продукте с единым языком интерфейса.

## Для кого (v1)

- Небольшие продуктовые / дизайн / dev-команды (студии, стартапы, агентства)
- 3–30 человек в одном workspace
- Нужны: проекты → задачи на доске, сроки, базовая активность, быстрый командный чат

Не целевая аудитория v1: крупный enterprise с сложным SSO/комплаенсом, полноценный CRM, HRIS.

## Ценность

1. **Один контекст проекта** — задачи, сроки, обсуждение и активность рядом.
2. **Прозрачность работы** — кто что делает, что изменилось, где блокеры.
3. **Спокойный UI** — минималистичный dark/light интерфейс без визуального шума.

## Принципы продукта

- Иерархия проста и жёсткая: Workspace → Projects → Tasks.
- Главный «hero»-сценарий: открыть проект и работать с Kanban.
- Dashboard (Home) — не аналитика/BI, а сводка «что у меня сегодня» (задачи, встречи, план недели, напоминания); графики и метрики продуктивности намеренно не делаем.
- **Task detail (desktop + mobile):** отдельная страница в app shell (не overlay sheet).
- Цвет и бейджи несут смысл (статус, тег, приоритет), не декор.
- Каждая фича v1 — минимально полезный срез, не «как у Notion/Linear целиком».

## MVP core (v1)

| # | Область | Что входит | Что не входит |
|---|---------|------------|---------------|
| 1 | Auth + Workspace | Magic Email (код) + JWT access/refresh, создание и выбор workspace, invite | OAuth, SSO, password login, org-иерархия над workspace |
| 2 | Projects | CRUD, список, избранное, шапка проекта | Портфели, портфолио-отчёты |
| 3 | Tasks | Kanban + List, карточка, статусы, assignees, теги, due date | Кастомные поля, зависимости, story points |
| 4 | Activity | Лента событий по workspace / проекту | Продвинутая аналитика, BI |
| 5 | Planning | Календарь / неделя по due date задач | Ресурсное планирование, capacity |
| 6 | Chat | Каналы workspace (самостоятельная фича) | Voice, видео, внешние интеграции мессенджеров, приватные каналы/DM |

Обсуждение задачи — через комментарии в самой задаче (TaskComment), не через чат-канал (см. [02-domain.md](./02-domain.md)).

## v1.1 (спроектировано, строится после ядра v1)

Домен и дизайн готовятся сейчас вместе с v1, но реализация — после того как Auth → Workspace → Kanban стабильны.

| # | Область | Что входит | Что не входит |
|---|---------|------------|---------------|
| 7 | Time-tracking | Живой таймер на задаче (start/pause/stop), учёт «сегодня» по задаче, лог интервалов в Task detail | Дневные лимиты/цели, биллинг по времени, ретроактивный ручной ввод |
| 8 | Meetings | Лёгкие календарные блоки (title, время, участники, опционально проект), отображаются в Planning и на Dashboard | RSVP/invite-флоу, повторяющиеся встречи, интеграция с внешним календарём, видео/звонки |
| 9 | Reminders | Личные заметки-напоминания (время + приоритет), отдельный экран `/reminders` | Общие/командные напоминания, повторяющиеся напоминания |

Появление этих фич сдвигает домашний экран: Dashboard (Home) собирает Today's tasks / Today's meetings / focus-таймер / compact Planning preview / Reminders / Recent activity — см. [03-ia-ux.md](./03-ia-ux.md).

## Success metrics (качественные на старте)

- Пользователь за 5 минут создаёт workspace, проект и первую колонку задач.
- Команда ведёт дневную работу в Kanban без переключения в другой трекер.
- Активность отвечает на вопрос «что изменилось с вчера».

## Вне скоупа продукта (пока)

- Биллинг / мульти-тарифы
- Мобильные native-приложения
- Публичные порталы клиентов
- Автоматизации / workflow builder
- Файловое хранилище как отдельный продукт

## Открытые вопросы

- Финальный нейминг и бренд-марка
- Глубина chat: только workspace-каналы или ещё DM в MVP

**Решено:** time-tracking нужен — отдельная сущность `TimeEntry`, живой таймер, v1.1 (см. таблицу выше).
